# data-maps/

Stores how data is structured and how it relates across the project.

## What belongs here

- Data maps
- Field mappings
- Source-to-target mappings
- Data relationships between entities and systems
- Related mapping documentation

## What does not belong here

- Actual data extracts or sample data
- SQL scripts implementing a mapping — those belong in `sql/`
- Reusable grouped queries — those belong in `query-packs/`
- Personal or sensitive data appearing in example values
