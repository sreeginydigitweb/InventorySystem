# sql/

Stores the SQL associated with this project.

## What belongs here

- SQL scripts
- Queries used by or for the project
- Database-related definitions, such as schema and table definitions
- SQL utilities and helper statements

## What does not belong here

- Connection strings, passwords, or any embedded credentials
- Exported result sets or extracted data
- Grouped, reusable query collections — those belong in `query-packs/`
- Field and source-to-target mappings — those belong in `data-maps/`
