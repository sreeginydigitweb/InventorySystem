# evidence/

Stores evidence that supports the work carried out in this repository.

## What belongs here

- Proof supporting decisions that were made, and the reasoning behind them
- Validation results and their supporting output
- Screenshots, exports, logs, and captured references
- Any other traceable proof that a piece of work was done as described

Evidence should be traceable: name files so a reader can tell what the evidence
relates to, and when it was captured.

## What does not belong here

- Unrelated working files, scratch notes, or temporary output
- Durable explanatory material — that belongs in `documentation/`
- Validation plans and check definitions — those belong in `validation/`
  (only the resulting evidence is stored here)
- Secrets, credentials, tokens, or personal data captured in screenshots or logs
