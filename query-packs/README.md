# query-packs/

Stores reusable, grouped sets of queries.

## What belongs here

- Query packs — related queries grouped so they can be reused together
- Grouped query definitions
- Query templates with clearly marked parameters
- Documentation describing what each pack is for and how to run it

## What does not belong here

- Individual standalone SQL scripts — those belong in `sql/`
- Query results and exported output
- Embedded credentials or connection details
- Field and source-to-target mappings — those belong in `data-maps/`
