# duplicate-risk-reports/

Stores the records used to prevent duplicated work and duplicated artifacts.

## What belongs here

- Duplicate-risk assessments carried out before new work begins
- Duplicate detection reports
- Naming collision findings — for example, folders differing only by hyphen,
  underscore, or case
- Records showing what already exists, so it is not rebuilt by mistake

Checking here before creating new structure is what keeps this repository from
accumulating near-identical folders and files.

## What does not belong here

- The duplicated artifacts themselves
- General validation results — those belong in `validation/`
- Unrelated project documentation — that belongs in `documentation/`
