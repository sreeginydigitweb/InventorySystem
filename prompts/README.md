# prompts/

Stores reusable prompts and the guidance for using them.

## What belongs here

- Reusable prompts intended to be used more than once
- Prompt specifications describing intent, inputs, and expected output
- Prompt templates with clearly marked substitution points
- Prompt-related operating instructions

## What does not belong here

- One-off prompts with no reuse value
- Secrets, credentials, or personal data embedded in prompt text
- Capability definitions and boundaries — those belong in `capability/`
- Recorded prompt output — that belongs in `evidence/` if it is being kept as
  proof
