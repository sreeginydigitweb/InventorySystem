# workflows/

The Mini-AIOS workflow area. Stores how work is carried out in this repository.

> **Note:** This is the top-level Mini-AIOS `workflows/` folder. It is **not**
> `.github/workflows/`, and it is not for GitHub Actions CI definitions. Those
> are a separate concern and should not be placed here.

## What belongs here

- Mini-AIOS workflow definitions
- Process instructions describing how a piece of work should proceed
- Workflow maps showing how stages connect
- Repeatable operating procedures

## What does not belong here

- GitHub Actions CI/CD pipeline definitions
- One-off notes about a single task
- Background explanatory material — that belongs in `documentation/`
